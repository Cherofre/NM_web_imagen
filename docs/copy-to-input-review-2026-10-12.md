# 结果图复制到输入区

日期：2026-10-12。分支：`codex/web-image-editing`。用户明确结果图下“继续编辑”用于复制所选结果图和该轮提示词，不是打开图片编辑器。

- 按钮改名“复制到输入区”，保留复制提示词的语义。图片读取及合并成功后再套用提示词；下载失败、参考数量已满或会话/引擎/模式已切换时保留原输入。
- 以已知输出来源或实际文件内容识别同图，不使用文件名/时间戳作为唯一依据。内容通过缓存的 SHA-256 比较；无 WebCrypto 的共享 HTTP 场景退回逐字节比较。候选读取串行执行，避免同时加载多份大型文件。
- 已有同图时保留最早的一份对象及其位置，合并所选图片已有的重复项；其余参考图顺序保持。保留对象身份使同一底图的遮罩继续有效。导出底图继承原图来源，避免 PNG 重新编码导致不必要的重复。
- 新图追加到参考区，沿用当前引擎数量上限；数量已满仍允许复用已有同图。复制中的按钮有加载反馈，重复点击不会启动并行复制。异步过程中参考列表变化会重新检查。
- 复制成功后提示新增/复用/合并数量，按钮暂显示“已复制到输入区”，对应参考图高亮 2.6 秒，仅横向定位参考条，不滚动整个会话；尊重减少动态效果设置。
- 根据追加反馈，参考卡片缩到 220 CSS px，文件名省略并保留完整名称 tooltip。底图/遮罩/编辑控件可换行，避免顶宽或遮挡删除按钮。
