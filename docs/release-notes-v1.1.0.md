## v1.1.0

NM Image Studio v1.1.0 正式发布。

### 桌面端

- 新增 Windows 独立桌面版，无需浏览器地址栏。
- 提供普通安装版、离线 WebView2 安装版和便携版。
- 支持独立设置、可自定义快捷键、窗口状态记忆和后台调试窗口。
- 桌面端与原网页端可以同时运行，数据和端口互不干扰。
- 桌面配置采用 Windows 用户级保护方式保存。

### 网页端

- 保留原有网页启动方式和历史数据兼容。
- 网页端和桌面端可以并行使用。

### 使用提示

- 普通安装版需要 Microsoft Edge WebView2 Runtime。
- 无网络或新电脑可使用离线 WebView2 安装版。
- 便携版升级时请保留应用目录下的 `data` 文件夹。
- 当前安装器尚未使用 Authenticode 代码签名，Windows SmartScreen 可能显示额外提示。
