# NM Image Studio v1.1.4 发行说明

本版修复生成数量、模型列表刷新，并改善桌面端的更新提示。

## 修复

- 将输入框下方的“会话提示”改为“附加提示词”，更容易看出这里可以填写生图时使用的补充内容。

- 修复开启聊天后配置弹窗底部被截断的问题：模型与聊天参数可以滚动查看，保存和关闭按钮保持可见。

- 读取模型列表后会清除渠道不再返回的旧模型；当前模型已移除时，切换到新列表第一项。读取失败会保留原配置。
- 桌面端在应用内更新源不可用时，仍会检查 GitHub 新版本，提示前往发布页手动下载。
- 修复更新下载进度不显示的问题，并补充下载失败后的手动下载指引。
- 长时间保持打开时也会定期检查更新；下载或等待安装期间，重复检查不会打断当前更新。

- **生成数量不再被渠道限制卡死**。部分中转渠道每次只允许生成 1 张（上游返回 `n currently supports 1 only`），
  此前把数量设为 2 张以上会直接报「上游服务拒绝了请求，请检查模型与生成参数。」。现在遇到这类渠道时，
  Studio 会自动改为**每次生成 1 张、按你设定的数量逐张补齐**，例如设 4 张就依次生成 4 张。
- 生成记录（历史）里新增 `count_strategy` 标记：`single-call` 表示一次请求就拿到全部张数，
  `per-image` 表示该渠道每次只能出一张、由 Studio 多次请求补齐。

## 需要注意

- 如果渠道一次只能生成 1 张，那么 **N 张 = N 次请求，耗时和费用都会按倍数增加**（渠道按次计费）。
  设置多张时请留意确认提示。
- 该能力只影响 GPT Image 2 通道；Banana 通道本来就是逐张生成，行为不变。

## 下载选择

- **普通安装版**：下载 `Setup-x64.exe`；如果电脑没有 WebView2，安装时需要联网下载。
- **离线安装版**：下载 `Offline-WebView2-Setup-x64.exe`，内含 WebView2 安装程序。
- **便携桌面版**：下载 `Portable-x64.zip`，完整解压后运行；系统需已有 WebView2。
- **网页版**：下载 `Web-x64.zip`，完整解压后双击启动脚本。

## 升级说明

- **1.1.3 及更早的桌面版需手动下载本次安装包。**旧版更新源缺少必要文件，不能保证收到 1.1.4 提醒，也无法直接在应用内完成此次升级。
- 更新便携版时，请先退出程序并保留原来的 `data` 文件夹；更新网页版时，请保留 `config.local.json` 和 `outputs`。
- 安装 1.1.4 后，未来发现新版本时可以收到窗口内提醒，并打开发布页手动下载。当前版本没有提供可供旧版直接安装的签名更新包。
