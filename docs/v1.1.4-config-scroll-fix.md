# 1.1.4 配置弹窗滚动修复

2026-09-23，用户反馈开启聊天后聊天模型下拉框被截断。

## 根因与修复

`.connection-drawer` 已有标题、导入提示、配置表单、操作按钮四个直接子项，但 CSS 仍只声明三行。配置表单没有最小高度约束或滚动容器，新增聊天字段后内容溢出，再被外层 `overflow: hidden` 裁切。

修复为四行 `auto auto minmax(0, 1fr) auto`，为 `.connection-layout` 设置 `min-height: 0` 和 `overflow-y: auto`。表单独立滚动，顶部标题和底部保存/关闭按钮保持可见。保留原生模型下拉框及现有响应式布局。

## 浏览器验收

使用独立静态服务和 Playwright 浏览器，虚拟 API Key；诊断请求被浏览器 mock 拦截，无真实生图调用。

- 修复前 1280×720：弹窗底部 y=702，操作按钮底部 y=891.94，表单 overflow=visible，无法滚动。
