## v1.1.1

NM Image Studio v1.1.1 发布。

### 桌面端

- 优化图片保存流程：支持快速下载、另存为，并在下载完成提示中直接打开下载文件夹。
- 恢复大图预览中的“在新窗口打开”操作，整理图片操作菜单层级。
- 改进 Windows 文件夹选择、存储位置切换和旧数据迁移提示。
- 保留首次启动设置、调试窗口、通知、任务栏提醒、托盘和自定义快捷键能力。

### 网页端

- 保持原有网页启动方式、历史数据和配置兼容。
- 网页端与桌面端可以同时运行，数据目录和端口相互隔离。

### 安装与升级

- 提供普通安装版、离线 WebView2 安装版和便携版。
- 本版本请使用安装器或便携包手动升级；已发布的更新签名密钥未在本次构建环境中提供，因此 `v1.1.0` 内置的自动更新 feed 暂不切换到 `v1.1.1`。
- 便携版升级时请保留应用目录下的 `data` 文件夹。
- 安装器尚未使用 Authenticode 代码签名，Windows SmartScreen 可能显示额外提示。
