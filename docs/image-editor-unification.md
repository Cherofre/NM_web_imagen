# 图片编辑统一评估

日期：2026-09-29。范围：网页版。评估方案已完成首轮试用实现，尚待用户视觉与真实渠道验收。

## 当前重合与区别

| 功能 | 用户意图 | 实际提交 | 建议 |
| --- | --- | --- | --- |
| 标注 | 画线、形状、箭头或文字表达修改要求 | 原图＋标注引导图＋说明 | 保留，复用评论输入、草稿及画布基础能力 |
| 位置评论 | 多个位置分别描述要求 | 原图＋编号引导图＋多条说明 | 保留，与标注共享说明数据，但不要求用户画图 |
| 擦除 | 移除选区内容并补全背景 | 底图＋Alpha 遮罩＋固定删除指令 | 并入局部修改，作为“擦除内容”预设 |
| 编辑遮罩 | 指定局部重新生成或替换内容 | 底图＋Alpha 遮罩＋自定义要求 | 改为面向用户的“局部修改”，保留遮罩兼容设置 |
| 移除背景 | 整体保留前景、生成透明背景 | 原图＋透明 PNG 参数＋固定指令 | 保留独立快捷操作，共用提交与返回逻辑 |

现有差异来自两个组件：MaskEditor 使用独立遮罩画布，支持 B/E/H、平移、填满、清空、Alpha 兼容模式，应用后返回输入区；ImageEditor 支持矢量标记、就地说明、按模式直接排队。两者的工具排列、缩放、笔刷尺寸单位及完成动作不同，因此看起来像两个产品。

## 推荐目标

一个编辑窗口，顶部统一返回和文件信息；底部统一工具、笔刷范围、快捷键、缩放、撤销重做和发送。主模式为：标注、位置评论、局部修改、移除背景。

“局部修改”包含“自定义修改”和“擦除内容”两个意图，复用同一个选区。自定义修改填写要求，擦除内容带默认指令。保留原有应用选区回到输入区的能力，作为次要动作，不再开另一套窗口。遮罩极性/渠道兼容选项收进高级设置。

三个易混操作应明确命名：标注橡皮擦只擦标记；选区橡皮擦取消选区；擦除内容才会调用 AI 删除原图中的内容。

## 实施顺序和验收

1. 共享基础布局、快捷键、缩放/坐标换算、范围圈和退出行为。保留两种内部数据：矢量标注与 Alpha 选区，避免强行转换而损失语义。
2. 将擦除和遮罩入口接入同一局部修改模式；切换意图保留选区。保持已有 standard/compat 遮罩语义和单次图片接口调用。
3. 统一草稿、说明输入、发送与回到原图；按来源决定保存选区是否可用。原图/选区/标注引导图分别导出，避免橡皮擦改变底图。
4. 验证小图和大图、窄屏、缩放后的笔刷范围、输入中快捷键隔离、撤销/重做、取消返回、意图切换、透明 PNG、重试和遮罩兼容。使用模拟上游验证参数与附件，再由用户实际渠道验收。

风险集中在遮罩极性、导出坐标和旧重试记录迁移，不能只替换界面。现有刷新后丢失未提交编辑草稿的问题也不因界面合并自动解决，应单独设计持久化。

## 本轮已做

新增 ImageEditorWorkspace，提供标注、位置评论、局部修改、移除背景四模式。访问过的模式在同一窗口保持挂载，切换保留各自画布、说明、撤销历史和缩放；两种内部数据模型继续独立，未强行转换矢量标记与 Alpha 选区。

网页版原遮罩入口接入局部修改；擦除内容与自定义修改共用选区。支持直接发送，也可保存选区到输入区沿用原工作流。兼容设置收进高级项，standard/compat 编码与单次图片调用保留。预览顶部重复遮罩按钮仅在桌面保留，网页从底部进入。局部自定义请求使用 local 操作标识，历史重试保留遮罩编码。

统一底部工具布局、B/E/H 工具切换、[ / ] 步长 8 调节笔宽、+/- 缩放和 0 适配；输入文字和组合输入时隔离绘图快捷键。新版局部笔宽按适配视图换算，与标注一致；原桌面遮罩的原图像素单位不变。标注橡皮擦只擦标记，局部“取消选区”只改遮罩，“擦除内容”才提交 AI 改图。
