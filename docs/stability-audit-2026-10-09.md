# 当前编辑分支与 v1.1.4 稳定性审查

日期：2026-10-09。审查基线：`codex/web-image-editing` 的 `24a5ec9`，以及原始发布标签 `v1.1.4`（`8a7a10b`）。

## 结论

审查已完成代码检查、实际事件处理函数回归、全量自动测试、构建、源码隔离启动和已发布包检查。发现并在当前分支修正了数量错误识别、编辑草稿身份、微小选区检查和键盘/指针交互问题。现有测试范围内未发现未解决的阻断问题。

这不是所有渠道与设备均稳定的保证。最新编辑界面的浏览器验收、真实渠道编辑效果和真实旧版安装升级仍未完成；已发布的 1.1.4 包未被本轮源码修复替换。

## 发现与修复

| 优先级 | 问题及触发条件 | 修复与证据 |
| --- | --- | --- |
| P2 | 1.1.4 的数量限制识别把带 `n`/`count` 的无关“不支持”错误误判为只能生成一张；中文“最多 10/16”也可能被当作 1 | 限定数量拒绝语义、补足中文数字边界；保留真实 `n currently supports 1 only` 和 `n=4 is not supported` 兼容。模型/尺寸拒绝带数量时，API 集成测试确认仅请求一次；真正单张限制继续补齐 |
| P2 | 重新打开结果图会创建新的 File 时间戳，草稿查找键随之改变，关闭后标注/评论不能恢复 | 用原结果 URL 或原参考文件身份构建草稿键；实际 `openImageEditor`、`onDraft`、`getDraft` 处理函数测试确认重新下载后恢复同图评论，其他图片和模式不串用 |
| P2 | 大图选区覆盖率按固定步长抽样，小于步长的选区会漏检，被误报没有选区 | 改为逐像素 Alpha 统计；百万像素图中只有一个选中像素、淡 Alpha 和空选区测试通过 |
| P2 | 中文输入法候选处理中按 Esc 会退出编辑；绘制途中撤销会修改正在使用的历史 | 组合输入优先交给输入法，绘制/平移途中不处理撤销等编辑快捷键；两个编辑器实际键盘处理函数回归通过 |
| P2 | 隐藏的模式会重算零尺寸适配比例，遮罩异步加载还可能抢走当前模式焦点；右键/第二指针可启动遮罩绘制 | 隐藏阶段保留 fit，异步聚焦检查可见性，绘制限制主按钮和单个活动指针。代码检查、类型检查与构建通过；实际多指针/模式视觉操作仍需人工复核 |
| P3 | 图片入口改名后，全量前端测试仍断言旧“编辑遮罩”文案 | 更新网页“局部修改”/桌面旧入口分支断言；全量测试由 238/239 修复为全部通过 |

主要改动：`app.py`、`App.tsx`、`ImageEditor.tsx`、`MaskEditor.tsx`、`imageEditorModel.ts`、`maskEditorModel.ts`。新增/增强测试位于 `test_upstream_jobs.py`、`editorInteraction.test.mjs`、`releaseConfigRegression.test.mjs` 及编辑器模型测试。
