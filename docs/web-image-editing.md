# 网页图片编辑测试版

日期：2026-09-27。分支：`codex/web-image-editing`。

## 使用

运行 `start_web.ps1`，打开 http://127.0.0.1:7861/ 。点击参考图或生成结果进入预览，下方显示四个入口。若已有旧页面，请刷新。

- 标注：画笔、文字、矩形、椭圆、箭头、颜色、选择移动、删除、撤销/重做。可下载标注 PNG；填写修改要求后发送原图与引导图。
- 添加评论：点击图片创建编号位置，在标点旁输入。Enter 或“完成此条”只完成当前评论，不发送；继续点击其他位置添加。右侧列表可切换评论，底部“发送全部 N 条评论”统一发送；空评论被忽略并重新编号。
- 移除背景：展示固定移除背景指令，点击发送生成一张透明 PNG。需要当前 GPT 渠道支持透明输出参数。
- 擦除：涂抹删除区域，支持笔刷尺寸、撤销/重做、清空和视图缩放，点击发送。

原图保留。编辑使用 GPT 图片连接配置，生成一张图片，不继承会话附加提示词、负面提示词或画面文字。主界面的参考图和生成参数保持原状。普通标注与下载不调用模型；点击发送会使用用户配置的渠道。

编辑器左上角“返回图片”或右上角关闭按钮返回原图片预览，可继续切换工具，保留预览的图库位置和缩放。未提交编辑草稿在当前页面内保留。Esc 返回上一层；正在输入评论时先收起该评论，再按一次返回预览。成功发送则退出编辑和预览，回到会话查看任务。

编辑草稿只在当前页面中保留，关闭编辑后可重开继续；刷新后未提交的草稿不会保留。提交后的原图、引导图/遮罩进入既有会话与重试流程。

## 验证

- Python 全部 297 项通过；Node 全部 233 项通过；Python 编译、TypeScript 与 Vite 构建通过。
- 浏览器实操：画笔、箭头、文字输入、撤销/重做、标注 PNG 下载、位置评论、擦除、移除背景入口、草稿重开恢复。
- 1280px 桌面与 390px 擦除视图截图位于 `output/playwright/image-edit-*.png`。
- 模拟上游请求：主配置故意设为 n=3 和 Responses，四种编辑均以 n=1 发送到 images/edits；标注/评论传两张参考图，背景/擦除一张；擦除带 mask；会话附加文字未混入。
- 模拟失败后重试移除背景，仍保留 background 类型和原参考图。
- 浏览器解码上传的 647×751 遮罩：17269 个完全透明像素、468047 个完全不透明像素，其余为边缘抗锯齿。选区极性与 Alpha 通道有效。
- 后端模拟验证背景请求携带 `background=transparent`、`output_format=png`，拒绝时不删参数重试；无图、无擦除遮罩、非法模式在上游前被拒绝。
