# NM Image Studio 1.1.7

- 新增 GIF 动画输出，可在「生成设置」中选择 GIF，并调整帧数和播放速度。
- 新增透明通道选项，自动联动 PNG/WebP 格式；结果会检查实际透明度，渠道未按要求返回时会保留图片并提示原因。
- 优化生成设置面板：格式、背景与质量更清楚，数量支持加减调整，改善小窗口和放大显示时的布局。
- 新增图片扩展参数 JSON，随连接配置保存，可填写渠道新增的图片参数。
- 修复更换存图目录时可能导致已有图库和历史图片失效的问题。迁移仅接受空文件夹，已有文件的目标目录会明确提示。
- 改善移除背景请求被图片服务安全审核拒绝时的提示。

GIF 和透明输出需要所选模型及渠道支持，请在生成设置中选择对应选项。扩展参数被渠道拒绝时会直接提示，不会自动删掉参数重试。

升级前请退出旧程序。安装版可覆盖安装；便携版请保留原有 `data` 文件夹。
