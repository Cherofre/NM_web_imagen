# 编辑窗口交互修正与检查

日期：2026-10-12。分支：`codex/web-image-editing`。用户反馈关闭后多一层预览、补充要求过小、默认滚动条、编辑画布不能滚轮缩放及默认适配尺寸变化，并要求扩大检查。

## 已修正行为

- 失败任务的“继续编辑”直接进入编辑窗口；X、返回按钮和退出用的 Escape 回到会话，不创建中间预览。关闭后优先恢复原入口焦点且不滚动会话。返回目标写入草稿，刷新后仍保持；旧 submitted/restored 草稿可按来源标识兼容恢复。
- 从图片预览进入编辑仍返回原预览，保留原预览缩放和图片身份。模式切换时使用同一返回目标，标题与关闭标签分别显示“返回会话”或“返回图片”。
- 标注整体要求默认至少 220 px 高，局部修改输入框至少 88 px，支持纵向调整；窄屏单独限制输入区占用，保留画布空间。编辑器 textarea、画布和侧栏使用深色滚动条，移除默认白色箭头区域。
- 标注与局部修改共用非 passive 的原生 wheel 监听，阻止画布滚动时的页面滚动/页面缩放。兼容鼠标和触控板、行/页滚动单位；范围仍为适配倍数 0.5–4。输入浮层和表单控件保留自己的滚动，绘制中或提交中不缩放。
- 网页默认适配移除 480 px 放大上限，横图、竖图及小纹理均使用实际可用画布。预览与编辑仍有侧栏/工具栏占用差异，不能承诺两者显示宽高完全相同；不改变原始图片或导出尺寸。旧独立桌面遮罩的尺寸策略保留。
- 标注范围圈在缩放/滚动后重新映射鼠标坐标，不必等待再次移动鼠标，避免范围圈短暂偏离。局部修改沿用已有屏幕分辨率范围圈。

## 验证与范围

- 272 项前端 Node 检查通过，新增 10 项及扩展已有恢复测试。执行实际事件处理与 effect 回调，覆盖退出目标、旧草稿与 IndexedDB 恢复、焦点、隐藏模式不重置、画布 fit、缩放上下限、滚轮单位、忙碌/绘制状态、输入区滚动、Ctrl+wheel 不与整窗缩放冲突及范围圈坐标重算。
- TypeScript 与网页生产构建通过，保留原有大分包及 boot-guard 警告。本轮没有调用真实生图、改渠道默认值、打包或发布。
- 构建后 49 项资源/发布门禁通过，7861 health 200 且实际提供新 JS/CSS；已检查深色滚动条和要求框样式出现在服务资源中。
- 真实浏览器仍未验收：重新尝试读取 IAB 的 7861 页面，管理员策略校验不可用，访问被拒绝；未使用其他工具绕过。DOM/CSS 视觉与真实滚轮手感需要用户刷新后确认，本地模拟不能替代此项。

人工复核顺序：失败继续编辑后关闭 → 预览进入编辑后返回 → 长补充要求及深色滚动条 → 画布滚轮与输入框滚动 → 横图/竖图/小图默认适配 → 模式切换保留内容与视图。
