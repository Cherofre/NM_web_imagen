# NM Image Studio v1.1.5 发行说明（待发布）

本版增加网页图片编辑，并修复任务重试、草稿恢复和多张生成的异常处理。

## 网页图片编辑

- 支持标注、位置评论、局部修改和移除背景。画完标注后可以直接填写说明，多处位置评论可以一起发送。
- 局部修改支持自定义要求和擦除内容，共用选区；笔刷范围、缩放和快捷键保持一致。
- 网页编辑草稿会在同一浏览器和访问地址下保存，刷新后可以恢复；失败任务可以继续编辑。
- 改善小图适配、文字边缘裁切、窗口返回路径和滚轮缩放。
- 图片上的“复制到输入区”会复制图片与本轮提示词，已有相同参考图会复用，并显示反馈。

## 输入与任务

- 附加提示词移到正文下方，宽窗口分为固定提示词、负面提示词、画面文字三个入口；手机和窄窗口保留统一入口。
- 展开提示词改为输入框右下角的图标，参考图卡片压缩为两行。
- 重试任务沿用该任务的参考图、遮罩和附加要求，避免误用当前会话输入或覆盖其他会话草稿。
- 修复活动队列过长时刷新遗漏任务，以及恢复局部编辑后保存选区缺少原图的问题。
- 多张生成补齐途中失败时，保留已经成功的图片并说明实际完成数量；异常的渠道用量字段不再导致有效图片报错。

## 使用说明

- 网页新编辑模式与桌面旧遮罩入口暂有区别，桌面保留现有遮罩编辑功能。
- 遮罩用于指导模型，不能保证选区外像素完全不变。移除背景会检查透明PNG，但主体保真和边缘质量仍取决于渠道与模型。
- 设置多张时可能需要多次上游请求，耗时和费用也会增加。部分完成的结果不会自动再次提交补齐。
- 草稿存储有数量和大小限制；清除网站数据、更换浏览器或访问地址后不能保证恢复。重要图片请下载保存。

## 升级与下载

- 普通安装版适用于可联网安装WebView2的电脑；离线安装版内含WebView2安装程序。
- 便携桌面版请完整解压，系统需已有WebView2；网页版完整解压后双击启动脚本。
- 更新便携版前退出程序并保留 `data`；更新网页版时保留 `config.local.json` 和 `outputs`。
- 本版以发布页手动下载安装为升级方式。旧版应用内自动下载和安装仍取决于匹配的签名更新包。
