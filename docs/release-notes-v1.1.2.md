## v1.1.2

NM Image Studio v1.1.2 发布。

### 配置管理

- 配置窗口顶部新增「GPT Image / Gemini」分页，不用关掉窗口就能切换管理两套配置；这里的分页只切换正在编辑的配置，不会改变主界面当前使用的引擎。
- 支持导出不含 API Key 的配置文件，通过选择文件或拖入配置窗口导入；导出的文件名带上当前配置名（例如 `nm-image-studio-config-SillyDream-1.1.2-2026-09-10.json`），一堆备份放在一起也能一眼分辨。已有相同地址的配置保留本机 Key。同 ID 但地址不同的配置会另建一份，需要单独填写 Key。
- GPT 与 Gemini 可以共用一套连接；新建共用连接会保留另一侧原有配置，编辑、重命名或解除共用只影响对应的一对配置。
- 修复保存后共用状态、Gemini 模型清单丢失，以及切换配置时误用其他配置模型清单的问题。
- GPT 配置可单独启用聊天，默认关闭；Gemini 和聊天模型也支持读取模型列表。
- 旧候选版本中无法确定配对关系的共用配置会保留地址和 Key，按独立配置加载，可重新开启共用。新导入的配置也需要在本机明确开启共用。

### 生图模型切换

- 配置弹窗里的「生图模型」改成下拉选择：可以直接从该配置的 API 地址读取可用模型列表（`/v1/models`），从列表里挑选，或手动填写任意模型名；每个配置各自记住自己的模型清单。
- 主界面生成区新增「生图模型」快捷切换，不用打开配置就能在当前配置的可用模型之间切换；GPT Image 与 Gemini 两个引擎都有这个入口，各自列出自己那一侧的模型。
- 中转站返回的模型清单会按引擎区分：GPT Image 的配置不再混入 Gemini 系列模型，Gemini 的配置也不会列出 GPT 系列模型；如果当前模型是手填的、不在已读取的清单里，切换器里会用虚线标出并说明原因。
- 切换模型只改当前配置，不影响其他参数；模型清单属于配置项，不会随每次生图请求发送给上游。

### 界面缩放

- 桌面端支持整个界面缩放：`Ctrl` + `+` 放大、`Ctrl` + `-` 缩小、`Ctrl` + `0` 恢复 100%，也可以用 `Ctrl` + 鼠标滚轮。
- 缩放范围 80%–160%，当前级别会被记住，下次打开应用保持上次的设置；每次调整都会在提示里显示当前百分比。
- 网页端不需要额外设置，直接用浏览器自带的缩放即可。

### 安装与升级

- 修复桌面端安装版与便携版打开后只有一片白窗、界面完全不显示的问题；已装过 1.1.2 的机器请用本次重新打包的安装包或便携包覆盖升级。
- 修复中文系统上安装界面仍显示英文的问题：安装器不再沿用上次记住的语言，按系统语言预选「中文(简体)」，也可以手动切换 English。
- 首次使用设置在「语言与存图位置」一步会显示真实的「文档\NM Image Studio」路径，不再是看起来被禁用的提示文案。
- 检测到已安装旧版本时直接覆盖安装，不再弹出“先卸载再安装”的选择页，安装目录沿用原位置。
- 提供普通安装版、离线 WebView2 安装版、便携版和网页包。
- 本版本请使用安装器或便携包手动升级；应用内自动更新暂不提供 1.1.2。
- 便携版升级时请保留应用目录下的 `data` 文件夹。
- 安装器尚未使用 Authenticode 代码签名，Windows SmartScreen 可能显示额外提示。

### 界面文案

- 面向用户的引擎名称由「GPT Image 2」改为「GPT Image」，引擎标识、接口路径和已有配置不受影响。
