# 网页编辑草稿与失败恢复

日期：2026-10-09。分支：`codex/web-image-editing`。用户授权继续完善草稿、失败恢复、小图/窄屏和移除背景约束；本轮没有真实上游生图请求。

## 行为

- 原图 Blob、标注对象、编号评论、输入要求、局部选区操作及原始遮罩保存在当前浏览器、当前站点的 IndexedDB。最多保留最近 20 份草稿记录，总量上限 150 MiB；提交副本也占用记录额度。连接配置和密钥不写入此存储。
- 编辑变化延迟 200 ms 保存，页面隐藏/离开时触发刷新写入。更新采用增量原子事务和串行写入；失败事务保留旧数据，内存编辑仍保留，并提示保持页面打开。浏览器清理站点数据、存储不可用、强制结束进程或仍未完成的最后写入不能保证恢复。
- 刷新恢复最近仍打开的编辑窗口及最后模式。主动返回/取消后不自动重开，原图再进入编辑时仍能取回草稿。恢复后“返回图片”有原图预览，预览携带稳定来源标识，避免下载 File 时间戳改变引起草稿错配。
- 提交生成留独立草稿副本，任务元数据携带恢复标识。失败消息保留具体错误并提供“继续编辑”，不会自动提交或付费重试。重新生成沿用恢复标识。
- 老任务或草稿被清理时，尝试读取原参考图和已保存遮罩；局部修改恢复原说明及 standard/compat 编码。旧标注/评论没有结构化草稿时提示重新添加，不声称能从成品引导图完整还原。原图不可读时明确提示重新添加。
- 输入浮层按可见视口限制宽度和高度，可在内部滚动；窄屏侧栏改用 border-box，低矮视口不再强制占用 180 px 画布。改变语言不会重新初始化并清空正在编辑的选区。选区基线解码与当前导出编码分别保存，切换兼容编码不会因父组件刷新而重置选区。
- 移除背景提示词增加原画布尺寸、原位置/大小/比例、禁止移动/放大/重新居中/裁切和光晕的约束。提示词不等于像素保真保证；本轮未付费验证其实际效果。

## 验证

- 259 项 Node 检查通过，新增 10 项确定性测试：IndexedDB 结构化复制与读写中止、原图/中文评论/选区恢复、容量和坏数据、浮层边界、真实发送/失败恢复/退出事件、旧任务恢复、异步请求过期、选区实际重放、串行增量保存。IDB 为本地事务模拟，不冒充真实浏览器刷新验收。
- 308 项全量 Python 检查通过；TypeScript 与网页生产构建通过，保留原有 boot-guard 和大分包警告。
- 构建后 49 项发布/资源缓存检查通过，账本 0 fail/4 项原有 warn。7861 `/api/health` 为 200，页面提供新构建文件。没有重启后台，没有改默认渠道、模型或连接配置，没有桌面打包、发布或推送。
- 真实浏览器交互仍未完成：打开 IAB 被管理员安全策略校验拒绝（无法验证策略）；没有改用其他工具绕过。需用户实际确认新版刷新恢复、模式切换及小图窄屏视觉。

本改动只为新版开始编辑后的内容提供保存，无法追补旧页面未曾落盘的内存草稿。
