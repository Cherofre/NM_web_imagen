# NM Image Studio v1.1.6 发行说明

本版补齐桌面端图片编辑。1.1.5 的桌面入口仍使用旧遮罩窗口，导致新增编辑功能无法从桌面打开；升级后与网页版使用同一套编辑流程。

- 图片预览下方提供标注、添加评论、移除背景和局部修改四个入口，编辑窗口内可切换模式。
- 标注和位置评论支持在图片旁填写说明；局部修改支持自定义修改、擦除内容及标准／兼容遮罩。
- 桌面端启用编辑草稿保存与恢复，失败任务支持继续编辑；退出程序前等待已产生的草稿写入。
- “下载标注图”使用原生保存窗口，可选择目录和文件名。
- 图片结果、参考图上的编辑入口统一显示“局部修改”，沿用底图复用、选区保留、滚轮缩放和笔刷快捷键。
- 统一参考图卡片的两行高度，带底图／遮罩标签与普通参考图的缩略图、删除按钮保持对齐。

移除背景、局部修改的实际效果仍取决于渠道与模型。移除背景要求返回透明 PNG，不会自动重试、换模型或补交任务。

请从本页手动下载升级。便携版升级前退出程序并保留 `data` 文件夹；网页版保留 `config.local.json` 和 `outputs`。普通安装版在缺少 WebView2 时需要联网，离线安装版包含其安装程序。
