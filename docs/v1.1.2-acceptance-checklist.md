# v1.1.2 验收清单

本清单给人工验收用。安装包打包后，按顺序过一遍即可；每项都写了「期望结果」，出现不符就是缺陷。

## 1. 生图模型切换（Studio 桌面端）

| 步骤 | 期望结果 |
| --- | --- |
| 打开配置弹窗，看「生图模型」一栏 | 是一个下拉框，下面还有一行可自由填写的输入框和一个「读取模型列表」按钮 |
| 点「读取模型列表」（当前配置的 API 地址就是真实中转站） | 按钮变成读取中，随后下拉里出现该地址真实提供的模型 id；抽屉里出现「已读取 N 个模型，保存配置后一并写入」的提示 |
| 展开下拉选择另一个模型 | 下方输入框同步变成该模型 id；顶部配置条里的模型名也跟着变 |
| 保存配置后重启应用 | 再打开配置弹窗，下拉里仍然有那几个模型（清单属于配置，会持久化） |
| 在配置里手填一个中转站没有的模型名 | 允许保存（自定义输入不被拦截），出错时由上游报错 |
| 主界面生成设置区点「生图模型」 | 弹出模型列表；列表只列出这个配置真正读取过的模型 id，不会出现内置预设混入 |
| 在该弹层里切换模型 | 当前模型立即改变，配置条同步更新；关闭弹层后设置仍然生效 |
| 再开第二个配置（不同 API 地址），切换过去 | 下拉/弹层**不会**沿用上一个配置读取到的模型清单（没读过就是空的，只显示当前模型+预设） |
| 用切换后的模型真实生成一张图 | 请求里带的是新模型 id，能正常出图 |

## 2. 界面缩放（桌面端）

| 步骤 | 期望结果 |
| --- | --- |
| 按 `Ctrl` + `+` / `Ctrl` + `-` | 整个界面连同侧栏、工具条一起缩放；提示显示当前百分比（如「界面缩放 110%」） |
| 按 `Ctrl` + `0` | 回到 100%，提示「界面缩放已重置为 100%」 |
| 连续放大到上限、缩小到下限 | 停在 160% / 80%，再按无效，不会出现布局散架 |
| `Ctrl` + 鼠标滚轮 | 与快捷键等效 |
| 关闭应用再打开 | 保持上次的缩放级别 |
| 打开遮罩编辑器，在里面滚轮 / `Ctrl`+滚轮 | 只缩放遮罩画布，**整个窗口的缩放不变** |
| 打开图片大图预览，同样滚动 | 只缩放预览图，窗口缩放不变 |
| 网页版（浏览器打开） | 不受这些快捷键影响，用浏览器自带缩放即可 |

## 3. 安装程序

> 重要：2026-09-10 早些时候发布的 1.1.2 桌面包打开是白屏（构建产物缺陷，已修复并用同版本号重新打包）。**如果那台机器已经装过旧 1.1.2，请用下面的安装包再覆盖装一次**，否则打开仍是白窗。

| 步骤 | 期望结果 |
| --- | --- |
| 在一台装有 v1.1.1 的机器上双击 v1.1.2 Setup | **不再出现**「已安装，请先卸载再安装」的选择页，直接进入安装 |
| 看语言选择页 | 中文系统预选「中文(简体)」，可以手动切成 English；装完再装第二次，仍然会问一次而不是被记住成上次的语言 |
| 安装目录 | 沿用原来的安装位置，不需要重新选 |
| 安装完成后启动 | 「关于」里显示 1.1.2，界面正常显示（**不应该**是白窗） |
| 首次使用设置（语言与存图位置） | 三个存图位置各显示自己的真实路径（「使用文档\NM Image Studio」显示 `文档\NM Image Studio` 的实际路径，不是灰字提示）；底部按钮与主界面风格一致、主按钮有圆角 |
| 用离线 WebView2 版 Setup 重复一次 | 行为一致，且不需要联网下载 WebView2 |

## 5. 边界与已知差异

- 更新签名密钥未在本次构建环境提供，`v1.1.0` 内置的自动更新 feed **不会**指向 `v1.1.2`，请用安装器或便携包手动升级。
- 安装器尚无 Authenticode 代码签名，Windows SmartScreen 可能提示。
- 经典网页界面（`/`）本次只同步了引擎文案（GPT Image 2 → GPT Image），未加入模型切换；如需一致，另开一项。
- 桌面端若界面加载失败，会在窗口底部显示一条「界面没有正常加载」提示（含原始错误），请把它截图反馈；这条提示正常启动时不会出现。
- 安装器烟测（`scripts/smoke_desktop_installer.ps1`）在本机因已有安装而按设计拒绝运行，真实覆盖升级仍由人工验收。
