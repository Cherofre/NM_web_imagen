# Studio 历史窗重构设计（v1.0.8）

## 背景

当前 Studio 同时存在左栏历史列表、完整历史窗、独立历史上下文弹窗和图片预览。入口会随左栏模式变化，完整历史窗与历史上下文又是两层独立弹窗。现有完整历史卡只展示每条记录的第一张图，多图批次不直观；列表/缩略图切换也与左栏历史列表重复。

用户已确认新的方向：不新增图片架或另一套历史数据，而是把现有历史窗改成同一功能的紧凑态、完整态和同窗详情态。`存图夹`与`历史窗`固定并列，点击历史窗先预览最近多条记录，按需展开全部历史。首轮手验进一步确认，“最近一批”不能只表示最新一条生成记录。

## 目标

1. 让最近多条生成记录在不占用工作区常驻空间的前提下快速可见。
2. 让完整历史窗成为图片优先的图库，不再复制左栏列表模式。
3. 让历史上下文在完整历史窗内部打开，避免双弹窗、焦点错位和返回位置丢失。
4. 让同一份历史状态驱动左栏、紧凑窗、完整窗、收藏和删除结果。
5. 保留现有 FastAPI 历史接口、`outputs/history.json`、收藏粒度和旧输出兼容行为。

## 信息架构

### 1. 左栏入口

- 左栏展开时固定显示两个并列入口：`存图夹`和`历史窗`。
- `历史窗`不再只在历史模式中出现。
- 历史模式的`刷新`改为历史数量行右侧的图标按钮。
- 原历史模式中的重复`历史窗`按钮删除。
- 左栏历史记录缩略图也表达批次：单图显示封面，双图显示两格，三/四图显示迷你拼图，并用角标显示总图片数。

### 2. 紧凑历史窗

- 点击左栏`历史窗`后，打开固定定位的轻量弹层，不推动左栏或工作区布局。
- 内容取最近 12 条具有图片的历史记录，每条记录显示一张代表缩略图。
- 多图记录显示图片数量角标；点击缩略图进入该条记录的现有图片预览，并可在预览中切换同批图片。
- 标题显示当前展示条数和总历史条数，明确这是最近多条记录而不是最新单批。
- 右上角提供`展开历史窗`与关闭。
- 不在紧凑态放筛选、收藏、删除和批量管理，避免再次复制完整历史窗。
- 点击外部、再次点击入口或按 Esc 关闭；关闭后焦点返回入口。

### 3. 完整历史窗

- 完整历史窗只保留图片网格，不再提供列表/缩略图切换；左栏历史承担记录列表职责。
- 保留收藏、日期、模型筛选和加载更多。
- 每条历史记录按批次展示：单图为完整缩略图，多图为最多四格的预览拼图，超过四张显示剩余数量。
- 每张拼图缩略图都可单独打开预览。
- 收藏仍属于整条历史记录，不改成单图收藏。
- 卡片底部保留`套用`与`更多`；图片特定动作继续由图片预览承载，避免多图时“作为参考图”指向不明。

### 4. 同窗详情

- 点击卡片正文后，完整历史窗内部切换为历史上下文详情，不关闭完整历史窗，也不另开第二层历史弹窗。
- 详情包含提示词、全部结果图、生成参数和返回信息。
- 顶部使用`返回历史`返回网格；返回时保留筛选、加载数量和滚动位置。
- 单图记录可保留底部`作为参考图`；多图记录通过点击具体图片进入预览后选择参考图。

## 状态与实现边界

- 使用一个判别联合状态管理历史表面：`closed`、`quick`、`browser`，其中`browser`可带`detailId`。
- 图片预览继续使用现有独立 lightbox 状态，关闭后返回原历史表面。
- 紧凑窗和完整窗共用现有 `history` 数组，不新增请求缓存或持久化模型。
- 不改变 `/api/history`、PATCH 收藏、DELETE 删除接口。
- 不增加第三方依赖，不改 `/classic`。

## 响应式与可访问性

- 紧凑窗使用固定定位并夹在视口内，避免被左栏 `overflow: hidden` 裁切。
- 桌面宽度约 300–340px；窄屏限制在可视区域内，缩略图自动降列。
- 完整历史窗在窄屏占据可用视口，工具栏换行，图片网格降为两列或一列。
- Esc 优先关闭更多菜单和图片预览；在详情态返回网格，在网格态关闭完整历史窗，在紧凑态关闭紧凑窗。
- 入口、展开、关闭、刷新和图片按钮具备可见 hover、active、focus 与 disabled 状态。

## 风险与控制

- 风险：同时改状态和视觉可能产生焦点回归。控制：先增加状态/源码契约测试，再替换 UI。
- 风险：多图拼图改变卡片高度。控制：使用固定预览比例和最多四格，不做瀑布流。
- 风险：原“参考图”快捷动作消失。控制：图片预览仍保留作为参考图；单图详情继续保留直接入口。
- 风险：大量原图解码仍可能较重。第一阶段继续使用现有 lazy loading；缩略图缓存接口作为独立性能项目，不混入本次重构。

## 验收标准

- `存图夹`和`历史窗`在会话、历史两种左栏模式下位置稳定。
- 点击`历史窗`显示最近 12 条图片历史，多图记录带数量角标；点击外部、入口或 Esc 能关闭。
- 点击`展开历史窗`进入同一份历史数据的完整网格，紧凑窗自动消失。
- 完整历史窗不再显示列表/缩略图切换，并能看出多图批次。
- 点击历史上下文在完整历史窗内部切换，返回后保留筛选、加载数量与滚动位置。
- 收藏、删除和刷新后，左栏与完整窗状态一致。
- 左栏历史列表能直接看出多图批次，不必进入详情后才发现同批还有其他图片。
- 320px 窄屏无水平溢出或被左栏裁切。
- Node 全量、尺寸门禁、TypeScript/Vite build、发布缓存门禁、Python compile 和 diff check 通过。
